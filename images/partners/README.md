# Logos de agencias – "Already trust us"

Coloca aquí los logos en **PNG con fondo transparente** para la franja del hero.

## Archivos requeridos

| Archivo | Agencia |
|--------|---------|
| `dunher-studies.png` | Dunher Studies SAS |
| `alegrias-agency.png` | Alegrías Agency |
| `yes-education-australia.png` | Yes Education Australia |
| `westberg-international.png` | Westberg International |
| `voom-agency.png` | Voom Agency |

## Recomendaciones

- **Formato:** PNG con canal alpha (fondo transparente).
- **Tamaño:** Altura sugerida ~80–120 px; el CSS limita con `max-h-11 sm:max-h-12` (~44–48 px en pantalla).
- **Proporción:** Preferiblemente horizontal o cuadrado para que se vean bien en la franja.

## Dónde conseguir los logos

1. **Dunher Studies SAS** – Sitio web o LinkedIn de la agencia.
2. **Alegrías Agency** – Sitio oficial o redes de la agencia.
3. **Yes Education Australia** – https://yesedugroup.com.au (logo en cabecera; pedir versión PNG transparente si hace falta).
4. **Westberg International** – Sitio o perfil oficial de la agencia.
5. **Voom Agency** – Sitio o redes de la agencia.

Si no tienes PNG transparentes, puedes usar herramientas como remove.bg para quitar el fondo de una imagen existente.
